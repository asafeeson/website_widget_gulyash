# Виджет слайдер с промокодом для установки на сайт платформы Гуляш через GTM
----------

## Инструкция по настройке виджета в GTM

Все операции проводятся в GTM (Google Tag Manager):
1. Зайдите в Google Tag Manager;
2. Выберите контейнер, соответствующий вашему сайту;
3. Создайте все теги и переменные в этом контейнере по инструкции далее;
4. Проверьте работоспособность виджета с помощью Preview;
5. В случае ошибок пишите разработчику @asafeeson;
6. Опубликуйте контейнер со всеми изменениями;
7. Для проверки на сайте очистите кеш браузера и зайдите на ваш сайт.

### Создание Tags (тегов) GTM
<br>

**Добавьте код модального окна и плавающей кнопки**
1. Создайте новый Tag типа Custom HTML и названием "Widget HTML";
2. Добавьте в созданный тег соддержимое файла widget.html;
3. В разделе Tag firing priority установите приоритет 5 (пять);
4. Сохраните результат.

<br>

**Добавьте логику виджета**
1. Создайте Tag типа Custom HTML и названием "Widget Logic JS";
2. Добавьте в созданный тег соддержимое файла logic.html;
3. В содержимом тега найдите строку и вставьте между квадратными скобками все нужные GTM переменные с настройками слайдов виджета.
    ```javascript
    var widgetData = [ список_переменных_GTM ];
    ```
    > ```javascript 
    > // Это может выглядеть, например, вот так. Все названия указаны условно.
    >
    >var widgetData = [{{widgetDataSushi}}, {{widgetDataPizza}}, {{widgetDebugData}}];
    >
    >//двойные скобки - это синтаксис вызова переменных в GTM
    >```
4. В разделе Tag firing priority установите приоритет 0 (ноль);
5. Сохраните результат.


<br>

**Добавьте стили виджета**
1. Создайте Tag типа Custom HTML и названием "Widget Style CSS";
2. Добавьте в созданный тег соддержимое файла styles.html;
3. В разделе Tag firing priority установите приоритет 10 (десять);
4. Сохраните результат.

<br>

**Добавьте настройки слайдов виджета**

1. Создайте новую User-Defined Variables переменную типа Custom JavaScript;
2. Добавьте в нее содержимое с информацией для каждого слайда по примеру настроек из файла slideData.js;
3. Дайте переменной понятное название, чтобы вы понимали, какую информацию она содержит;
4. Для размещения слайдов в виджете на сайте добавьте переменную в список widgetData как это указано выше в инструкци.

## Если нужно несколько модальных окон для разных источников

Если вам нужно, чтобы для разных источников перехода срабатывал виджет с разным содержимым (слайды, промокод, фотографии), то для каждого источника переходов надо создать свою переменную с информацией слайдов. 

Например, если ваши клиенты переходят с сайтов offer-one.ru и offer-one.ru, то для каджого сайта надо создать переменную со слайдами, например SlidesOfferOneData и SlidesOfferTwoData. 

Ключевое отличие, что в пункте referrer надо будет указать адрес того сайта с которого переходит пользователь. В таком случае виджет автоматически определит источник перехода и если это один из этих сайтов, то пользователь увидит виджет с нужным содержимым.

Например:
```json 
    // Для сайта offer-one.ru:
    {
        referrer: "offer-one.ru",
        slideOne: {...},
        ...
    }

    // Для сайта offer-two.ru:
    {
        referrer: "offer-two.ru",
        slideOne: {...},
        ...
    }
```

## Установка GTM на сайт

1. Зайдите в Google Tag Manager и выберите контейнер, соответствующий вашему сайту.
2. Скопируйте код контейнера GTM:
    - Перейдите в раздел "Администратор" → "Установить Google Tag Manager".
    - Скопируйте оба кода (для `<head>` и `<body>`).
3. Вставьте скопированные коды на ваш сайт:
    - Код для `<head>` вставьте перед закрывающим тегом `<head>`.
    - Код для `<body>` вставьте сразу после открывающего тега `<body>`.
4. Сохраните изменения и опубликуйте сайт.

<br>

## Проверка работоспособности виджета

1. Откройте сайт, на который установлен виджет, в браузере.
2. Включите режим предварительного просмотра в GTM:
    - Зайдите в Google Tag Manager;
    - Нажмите кнопку "Предпросмотр" в правом верхнем углу;
3. Обновите страницу сайта и убедитесь, что виджет отображается корректно.
4. Проверьте консоль браузера (F12 → вкладка "Console") на наличие ошибок, связанных с виджетом:
    - Ошибки обычно отображаются красным цветом и содержат текст, указывающий на проблему.
    - Ищите сообщения, связанные с файлами виджета, например `widget.html`, `widgetScript.html`, или `styles.html`.
    - Если в консоли есть сообщения об ошибках, проверьте корректность кода и настройки переменных в GTM.
5. Убедитесь, что все теги GTM, связанные с виджетом, срабатывают корректно:
    - В режиме предварительного просмотра GTM проверьте, что все созданные теги активируются на странице.
6. Если виджет работает корректно, опубликуйте изменения в GTM, нажав "Отправить" → "Опубликовать".
